# Korean Flashcards 🇰🇷

A simple Korean vocabulary flashcard app built with Python and Tkinter.

## Features

* Displays Korean words.
* Shows the English meaning after a few seconds.
* Mark words as known or unknown.
* Uses a CSV file to store vocabulary.

## Technologies

* Python
* Tkinter
* Pandas

## How to Run

```bash
python main.py
```
